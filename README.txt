CUSTOMER COMPLAINT ANALYZER
============================

Features:
1. Enter customer complaint as text.
2. Speech-to-text using browser microphone.
3. Complaint category detection.
4. Priority detection.
5. Sentiment detection.
6. Keyword extraction.
7. Confidence score.
8. Responsive website.

REQUIREMENTS
------------
- Node.js installed on the computer
- Modern browser (Chrome recommended for speech input)

HOW TO RUN
----------
1. Open this project folder in VS Code.
2. Open Terminal / PowerShell.
3. Run:

   npm.cmd install

4. Then run:

   npm.cmd start

5. Open:

   http://localhost:5000

IMPORTANT
---------
If "npm" is blocked in Windows PowerShell, use npm.cmd as shown above.

SAMPLE COMPLAINTS
-----------------
"My order is delayed and has not arrived yet."
"My product arrived damaged and the quality is very poor."
"I was charged twice for the same payment."
"Customer support is not responding to my problem."
"My account is blocked and I cannot login."

NOTE
----
This is an academic/demo analyzer using rule-based text analysis.
It does not make real-world customer-service decisions.
